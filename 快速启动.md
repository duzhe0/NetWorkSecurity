# 快速启动指南

## 1. 环境准备

```bash
pip install pandas numpy scikit-learn xgboost torch matplotlib seaborn joblib
```

## 2. 原始数据文件（出发点）

以下 3 个文件是唯一的外部输入，其余文件均由代码自动生成：

| 文件 | 用途 |
|------|------|
| `Train/KDDTrain+.txt` | 完整训练数据集 |
| `Train/KDDTrain+_20Percent.txt` | 20% 子集（可选） |
| `Train/train_test` | 外部独立测试集（默认） |
| `Train/KDDTest+.txt` | 标准 KDDTest+ 测试集（22544 条） |
| `Train/KDDTest-21.txt` | KDDTest-21 测试集（11850 条） |

另外 `Train/encoder_multiclass_23_classes.txt` 是预置的 23 类标签映射文件（手动维护，不需每次生成）。

## 4. 执行步骤（按顺序，从头复现）

### 步骤 1：数据预处理

```bash
python data_preprocessing/data_preprocessing.py --dataset full --data_dir Train
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--dataset` | `full` | `full` 用 `KDDTrain+.txt`，`20percent` 用 `KDDTrain+_20Percent.txt` |
| `--data_dir` | `../Train` | 数据目录，从项目根运行应为 `Train` |

生成文件（10 个）：
- `Train/KDDTrain_preprocessed_{train,val,test}.csv`
- `Train/encoder_onehot.pkl`
- `Train/scaler_robust.pkl`
- `Train/encoder_service_embedding.pkl`
- `Train/preprocessing_metadata.pkl`
- `Train/encoder_multiclass_23.pkl`
- `Train/encoder_category_5.pkl`
- `Train/encoder_category_5_classes.txt`

### 步骤 2：训练 Two-Stage 模型

```bash
python models/two_stage/two_stage_model.py
```

生成文件（2 个）：
- `model_stage1_best.pth` — Stage1 二分类模型（Normal vs Attack）
- `model_stage2_best.pth` — Stage2 23 类分类模型

### 步骤 3a：生成混淆矩阵 & 结果 CSV

```bash
# 默认阈值 (s1=0.5, s2=0.5)
python models/two_stage/save_cm.py

# 指定阈值
python models/two_stage/save_cm.py --threshold 0.7

# 独立 s1/s2 阈值
python models/two_stage/save_cm.py --s1_threshold 0.5 --s2_threshold 0.7
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--threshold` | `None` | 同时设置 s1 和 s2 |
| `--s1_threshold` | `0.5` | Stage1 攻击检测阈值 |
| `--s2_threshold` | `0.5` | Stage2 置信度拒绝阈值 |
| `--test_file` | `train_test` | 外部测试文件，可选 `train_test` / `KDDTest+` / `KDDTest-21` |

生成文件：
- `models/two_stage/results_two_stage_external_test{_th07 或 _s105_s207}.csv`
- `models/two_stage/cm_external{_th07 或 _s105_s207}.npy`

### 步骤 3b：双阈值网格搜索（可选）

```bash
python models/two_stage/grid_search_threshold.py
```

生成文件：
- `models/two_stage/grid_search_dual_threshold.csv` — 25 组 (s1, s2) 组合结果

### 步骤 3c：Stage1 ROC 曲线（可选）

```bash
# train_test（默认）
python models/two_stage/eval_roc.py

# 指定测试集
python models/two_stage/eval_roc.py --test_file KDDTest+.txt
python models/two_stage/eval_roc.py --test_file KDDTest-21.txt
```

生成文件：
- `Visualization/roc_stage1_{test_file}.png` — Stage1 Normal vs Attack 二分类 ROC 曲线

输出指标：AUC、最优阈值 (Youden's J)、TPR/FPR、以及 s1=0.5 处的 TPR/FPR。

### 步骤 4a：生成混淆矩阵可视化

```bash
# 内部测试集
python Visualization/visualize_confusion_matrices.py --model two_stage --source internal

# 外部测试集（默认阈值）
python Visualization/visualize_confusion_matrices.py --model two_stage --source external

# 外部测试集（指定阈值）
python Visualization/visualize_confusion_matrices.py --model two_stage --source external --threshold 0.7

# 外部测试集（自定义后缀，如 s1=0.5, s2=0.7）
python Visualization/visualize_confusion_matrices.py --model two_stage --source external --cm_suffix "_s105_s207"
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--source` | `internal` | `internal` 或 `external` |
| `--model` | 无 | 单模型模式：`two_stage` / `xgboost` / `dnn` 等；不指定则 XGBoost vs DNN 对比模式 |
| `--threshold` | `None` | 阈值（如 0.7） |
| `--cm_suffix` | `None` | 自定义文件后缀（如 `_s105_s207`） |

生成文件：
- `Visualization/confusion_matrix_two_stage_{internal,external}{后缀}.png`

### 步骤 4b：生成分析报告

```bash
python Visualization/generate_cm_report.py --model two_stage --source external --version v1 --threshold 0.7
```

| 参数 | 必填 | 说明 |
|------|:---:|------|
| `--model` | 是 | 模型名称：`two_stage` |
| `--source` | 是 | `internal` 或 `external` |
| `--version` | 是 | 实验版本号（如 `v6_binary_pm3`） |
| `--threshold` | 否 | 阈值 |
| `--cm_suffix` | 否 | 自定义后缀 |

生成文件：
- `AIMemory/{version}_two_stage_{source}_cm{后缀}.md`

## 5. 一键复现（完整 Pipeline）

```bash
# 1. 预处理
python data_preprocessing/data_preprocessing.py --dataset full --data_dir Train

# 2. 训练
python models/two_stage/two_stage_model.py

# 3. 双阈值网格搜索
python models/two_stage/grid_search_threshold.py

# 3c. Stage1 ROC 曲线（3 个外部测试集）
python models/two_stage/eval_roc.py
python models/two_stage/eval_roc.py --test_file KDDTest+.txt
python models/two_stage/eval_roc.py --test_file KDDTest-21.txt

# 4. 生成混淆矩阵（默认阈值 + 最优阈值）
python models/two_stage/save_cm.py
python models/two_stage/save_cm.py --test_file KDDTest+.txt
python models/two_stage/save_cm.py --test_file KDDTest-21.txt
python models/two_stage/save_cm.py --s1_threshold 0.5 --s2_threshold 0.7
python models/two_stage/save_cm.py --s1_threshold 0.5 --s2_threshold 0.7 --test_file KDDTest+.txt
python models/two_stage/save_cm.py --s1_threshold 0.5 --s2_threshold 0.7 --test_file KDDTest-21.txt

# 5. 可视化
python Visualization/visualize_confusion_matrices.py --model two_stage --source external
python Visualization/visualize_confusion_matrices.py --model two_stage --source external --cm_suffix "_s105_s207"
# _s105_s207 解码: s105 = s1=0.5, s207 = s2=0.7 (去掉小数点,前缀s1/s2)
# 对应 save_cm.py --s1_threshold 0.5 --s2_threshold 0.7 的产物
python Visualization/visualize_confusion_matrices.py --model two_stage --source internal

# 6. 报告
python Visualization/generate_cm_report.py --model two_stage --source external --version v_latest
python Visualization/generate_cm_report.py --model two_stage --source external --version v_latest --cm_suffix "_s105_s207"
python Visualization/generate_cm_report.py --model two_stage --source internal --version v_latest
```
