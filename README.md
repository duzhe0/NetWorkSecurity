# NetWorkSecurity
开发一款基于公开数据集的入侵检测系统软件，该软件需能够对网络流量数据进行分析、识别，以分类各种网络攻击行为。需要完成软件的完整设计、编码、测试和文档撰写工作，并提交完整的软件代码、测试报告和设计文档。最终成果需要选择并实现至少一种深度学习算法，具备一定的准确性和效率，能够对公开数据集中的攻击类型进行有效识别

具体功能

• （1）数据预处理：能够读取并预处理教师提供的数据集，处理缺失值、异常值等，并

进行必要的特征选择和降维；需要对数据进行规范化或标准化处理。周二检查项。

• （2）模型训练：选择并实现至少一种深度学习算法，对数据集进行训练，建立入侵检

测模型，需要实现攻击的多分类。周三检查项。

• （3）模型优化：对模型参数进行调优，以达到更优的检测性能，提供可视化界面和实

验结果图表。周四检查项。

• （4）性能评估：使用教师提供的数据集测试模型，评估指标可以包括准确率、精确率、

召回率、F1值、ROC曲线等。周五检查项。

（5）加分项：

•  可以对不同算法的性能进行比较

•  提供友好的用户界面，方便用户导入数据、训练模型、进行检测和查看结果

•  研究并尝试解决数据集存在的类不平衡问题
